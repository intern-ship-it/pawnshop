# Landing page images

Drop the photographs for the public landing page (`/`) in this folder.
Filenames are referenced from `src/pages/Landing.jsx` and must match exactly.

## "What our Pawn Shop accepts?"

| File                   | Image                          |
| ---------------------- | ------------------------------ |
| `gold-jewellery.jpg`   | Gold necklace on navy fabric   |
| `gold-bars.jpg`        | Stacked 999.9 fine gold bars   |
| `gold-coins.jpg`       | Loose gold bullion coins       |

Recommended: 4:3 crop, ~800×600, JPEG, under 200 KB each.

Any missing file falls back to a branded placeholder tile automatically —
the page will not show a broken image.
